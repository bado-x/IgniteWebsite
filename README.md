# Ignite - Youth Leadership Website

A modern, responsive website for Ignite youth leadership organization built with Next.js and Tailwind CSS.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Fully responsive across all devices
- **Performance Optimized**: Fast loading with optimized assets
- **Contact Form**: Integrated with Google Sheets for form submissions
- **SEO Optimized**: Meta tags and structured data for better search visibility

## 🛠️ Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Animations**: CSS animations + @paper-design/shaders-react
- **Icons**: Lucide React
- **Font**: Syne (Google Fonts)
- **Analytics**: Vercel Analytics

## 📱 Sections

- **Hero**: Eye-catching landing section with call-to-action
- **About**: Vision, Mission, and Approach cards
- **Services**: Leadership Training, Mentorship, Events, Community Impact
- **Contact**: Contact form with location and social media links
- **Footer**: Quick links and social media integration

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
